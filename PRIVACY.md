# Privacy Policy — "Don't Waste Your Time" site blocker

This extension does not collect, transmit, sell or share any personal data.

- The only data it stores is the list of sites you choose to block. It is kept in `chrome.storage.sync`, which Chrome stores in your own browser and, if you have Chrome Sync turned on, in your Google account. The developer has no access to it.
- The extension makes no network requests and contains no analytics, ads or remote code.
- Blocking is done by Chrome itself through the `declarativeNetRequest` API, so the extension never reads the pages you visit or your browsing history.

Contact: open an issue in this GitHub repository.
