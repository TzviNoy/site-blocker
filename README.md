# אל תבזבז את הזמן שלך – חוסם אתרים

תוסף ל-Chrome (וגם Chromium, Brave ו-Edge). כשנכנסים לאתר מהרשימה, מוצג במקומו מסך שחור עם הכיתוב הענק "אל תבזבז את הזמן שלך".

## מבנה הריפו
| נתיב | מה יש שם |
|---|---|
| `extension/` | התוסף עצמו, כלומר מה ש-Chrome טוען |
| `scripts/package.sh` | בונה את `dist/site-blocker-<version>.zip` להעלאה לחנות |
| `store/` | טקסטים לדף בחנות, צילומי מסך ותמונת קידום |
| `PRIVACY.md` | מדיניות פרטיות (החנות מבקשת קישור אליה) |

## התקנה מקומית (בלי החנות)
1. פותחים את `chrome://extensions` ומפעילים את **Developer mode**.
2. לוחצים על **Load unpacked** ובוחרים את התיקייה `extension/`.
3. נועצים את האייקון בסרגל (סמל הפאזל ← סיכה).

אחרי שינוי בקוד לוחצים על ⟳ ליד התוסף.

## עריכת הרשימה
- **מתוך האתר:** אייקון התוסף ← "חסום את האתר הזה" (או "בטל חסימה" כשנמצאים במסך החסימה).
- **בדף הניהול:** אייקון התוסף ← "ניהול רשימת האתרים". מוסיפים דומיין או קישור מלא, ומוחקים עם "הסר".
- **עריכה כטקסט:** בתחתית דף הניהול, אתר בכל שורה. שימושי לייבוא ולייצוא.

חסימה של דומיין חוסמת גם את כל תתי-הדומיינים שלו.

## פרסום גרסה בחנות
1. מעלים את `version` ב-`extension/manifest.json`.
2. מריצים `./scripts/package.sh`.
3. מעלים את ה-zip מ-`dist/` ב-[Developer Dashboard](https://chrome.google.com/webstore/devconsole). את הטקסטים לדף לוקחים מ-`store/LISTING.md`.

## מעבר מהגרסה המקומית לגרסה מהחנות
לגרסה מהחנות יש מזהה תוסף אחר, ולכן היא לא רואה את הרשימה של הגרסה המקומית. כדי להעביר את הרשימה: מעתיקים אותה מ"עריכה כטקסט" בגרסה המקומית, מדביקים בגרסה מהחנות, ואז מסירים את הגרסה המקומית.
